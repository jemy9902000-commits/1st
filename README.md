# Clinical Evidence Library

An Excel workbook for tracking clinical trials and references across the rare disease portfolio: MPS IVA (Vimizim), MPS VI (Naglazyme), CLN2 (Brineura), achondroplasia (Voxzogo) and PKU (Palynziq), plus competitor products.

`Clinical_Evidence_Library_TEMPLATE.xlsx` is the empty template. It has four sheets:

- **Library**: one row per trial or reference. Pick a product and the therapy area, company and own/competitor fields fill in automatically. The sheet can be filtered and sorted, pivotal trials show in bold, and rows from internal documents are flagged in red.
- **Summary**: counts per product (total, pivotal, trials, real-world, guidelines, internal) with the earliest and latest year.
- **Products**: the product list behind the dropdowns. Add competitors here.
- **Read Me**: how to use the workbook.

The Library sheet is an Excel table named `Library`, so it can be loaded straight into Power BI.

The filled-in version is kept out of this repository because some entries come from internal company material.
